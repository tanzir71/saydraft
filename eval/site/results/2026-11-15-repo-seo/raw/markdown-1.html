Verified product facts

  • Windows 10/11 x64 app; source setup uses 64-bit Python 3.13.
  • App code is MIT. Dependencies and model weights retain their own licenses.
  • Local Parakeet/Whisper speech recognition, rules cleanup and optional local Qwen cleanup. Rules-only dictation needs no cleanup model.
  • Default hold shortcut Ctrl+Win, hands-free capture, cancellation, History, Dictionary, Snippets, per-app Style, Scratchpad and Notes.
  • Speech model setup requires a reviewed Download/Resume action. Installed files are reused. Bengali and Arabic use a shared optional multilingual speech model.
  • Audio retention and app update checks default off. Speech and cleanup have no cloud fallback. Updates, when enabled, link to releases for manual installation.
  • Translate and Command are experimental Pro features. Pro describes a hardware tier in this app, not a paid subscription.
  • An older unsigned verification pre-release, v0.1.0-dry-run.20261114, is public. It predates current source and does not establish current binary or signing acceptance. Current-source setup is recommended; signed distribution and broader physical Windows acceptance remain unfinished. Accuracy and general performance claims remain unqualified.
  • Ask and meeting notes/speaker labels are implemented as experimental Pro features with explicit setup/opt-in. Broader answer/speaker/summary quality and full live/frozen/physical meeting acceptance remain open.

These facts come from the README, model guide, privacy boundary, Translate guide, packaging guide and parity plan.
