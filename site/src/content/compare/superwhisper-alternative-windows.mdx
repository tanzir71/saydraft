Superwhisper is already available on Windows. It also supports macOS and now
has an official Linux release. Choosing Saydraft is a decision about licensing,
model workflow and project maturity, rather than access to a Windows app.

Both projects can use local speech models. Superwhisper also provides cloud
choices, so its network behavior depends on the selected model and processing
mode. Its [introduction](https://superwhisper.com/docs/get-started/introduction)
explains the distinction, including supported local AI processing.

## Compare what you would install

| Choice | Saydraft | Superwhisper |
| --- | --- | --- |
| Local speech | [Installed Parakeet/Whisper models](https://github.com/tanzir71/saydraft/blob/main/docs/MODELS.md) | [Local voice models](https://superwhisper.com/docs/get-started/introduction) |
| App license | [MIT-licensed source](https://github.com/tanzir71/saydraft/blob/main/LICENSE) | [Commercial application terms](https://superwhisper.com/terms) |
| Desktop availability | [Windows development project](https://github.com/tanzir71/saydraft) | [Windows and macOS](https://superwhisper.com/download), [Linux](https://superwhisper.com/linux) |
| Cost | [Free](https://github.com/tanzir71/saydraft) | [Free local dictation; paid Pro options](https://superwhisper.com/docs/billing/plans) |

Superwhisper's website lists Pro at US$8.49 monthly, US$84.99 yearly or US$249.99 once.
Store prices and current terms can differ; use the vendor's plan page when
making a purchase decision. Saydraft's source has no subscription or paid unlock.

## Choosing a workflow

Try the same representative phrases in the models you plan to use. A local
model can trade memory, speed and recognition quality differently from another
local model. Neither shared use of Whisper nor a larger file establishes equal
accuracy or performance.

Saydraft's <SiteLink path="offline-dictation-windows/">offline guide</SiteLink>
explains explicit setup, hardware and privacy limits. Its public accuracy record
includes substantial errors in some languages; broader acceptance is ongoing.
Current source builds and experimental features need review before reliance in
an everyday workflow.
