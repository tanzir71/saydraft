Saydraft is a free, MIT-licensed project for local Windows dictation. Consider it
for drafting messages, notes and documents when you want inspectable source and
local models. A stable public release and broader workflow qualification are
still pending.

Dragon Professional v16 is a commercial Windows application with a broader
established dictation and command workflow. Its
[data sheet](https://dragon.nuance.com/shared/data-sheets/ds-dragon-professional-v16-en-us.pdf)
describes local desktop recognition and internet requirements for download and
automatic activation. Keep it separate from Dragon Professional Anywhere,
which is a different product.

## Compare the scope

| Choice | Saydraft | Dragon Professional v16 |
| --- | --- | --- |
| Recognition | [Local speech models](https://github.com/tanzir71/saydraft/blob/main/docs/MODELS.md) | [Desktop recognition](https://dragon.nuance.com/shared/data-sheets/ds-dragon-professional-v16-en-us.pdf) |
| License | [MIT-licensed app source](https://github.com/tanzir71/saydraft/blob/main/LICENSE) | [Commercial licensed software](https://dragon.nuance.com/en-us/dragon-professional) |
| Main focus | [Writing and local text workflows](https://github.com/tanzir71/saydraft) | [Professional dictation and commands](https://dragon.nuance.com/en-us/dragon-professional) |
| Cost | [Free source](https://github.com/tanzir71/saydraft) | [Contact the vendor for current pricing](https://dragon.nuance.com/en-us/dragon-professional) |

The current official Dragon page directs buyers to sales. Confirm current
pricing and the license plan that fits your workflow with the vendor.

## Evaluate with your own documents

If your workflow depends on application control, specialist vocabulary or an
accessibility command system, test those requirements explicitly before changing
tools. Saydraft has not completed broad physical or accessibility acceptance.
Dictation can reduce the amount of keyboard input needed for a writing task.

Start with <SiteLink path="docs/getting-started/">setup</SiteLink> and the
<SiteLink path="offline-dictation-windows/">offline dictation guide</SiteLink>.
Compare representative names, numbers and long passages rather than assuming
that one model's result predicts another's.
