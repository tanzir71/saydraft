Set up once. Then go offline.

Review the recommended model, size and license, then start its download in setup. Progress and pause/resume are available. Later launches reuse your installed files. The setup walkthrough covers microphone selection, models, shortcuts and a first practice draft.

Arabic, Bengali, Chinese, Hindi, Indonesian, Japanese, Korean, Malay, Thai and Urdu use the optional shared All languages model. Download it once; there are no separate language packs. Portuguese, including Brazilian Portuguese, is also covered by the default model. Review language and model choices before choosing a package.

A few useful answers.

Is a signed Windows installer available here?+

Saydraft is in development. Use the current source instructions and check GitHub Releases for published artifacts. This page does not advertise an unpublished installer or package-manager command.

Will models download automatically?+

No. Setup shows the recommendation, size and license before you choose Download / Resume. You can pause; later launches reuse verified installed files.
