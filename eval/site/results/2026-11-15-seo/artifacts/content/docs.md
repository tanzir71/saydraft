# Saydraft Documentation — Offline Voice Typing on Windows

Canonical: https://tanzir71.github.io/saydraft/docs/

Set up Saydraft, learn Windows dictation shortcuts, choose local speech models, adjust styles and dictionary, and verify offline behavior.

Facts checked: 2026-11-14

Saydraft turns speech into a local draft on Windows. Start with a compatible installed model, then choose the shortcuts and cleanup that fit your work. The app is in development; review its results before using them elsewhere.

## A few useful answers.

### Where should I start?

Follow Getting started to review the current source build, select an input, explicitly install compatible speech models and try a short practice draft.

### Are the Pro features a paid plan?

No. Saydraft is free and open source. Lite, Standard and Pro describe local hardware/performance profiles; experimental editing still needs its compatible local model.
