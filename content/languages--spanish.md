# Spanish voice typing for Windows.

Español

Dictate Spanish messages, emails and notes on your own Windows PC. Spanish speech recognition is included in Saydraft’s default Parakeet v3 model and is also available through All languages.

Choose Spanish, language code es, in Languages. A Spanish-only pin uses Parakeet v3 when automatic model choice is enabled. Combining Spanish with a language outside that model’s set, such as Japanese or Indonesian, selects the shared All languages model instead.

Spanish is included in Parakeet v3, the default speech model. All languages is also compatible. No separate language pack is required.

## How to set up Spanish dictation

- Follow the [current download and source setup instructions](https://tanzir71.github.io/saydraft/download/). Saydraft is a development preview for Windows 10 and 11.

- In Hub → Settings → Models, review the required model’s size and license. Choose Download / Resume if it is missing; Pause is available.

- Open Languages, enable automatic model choice, and select Spanish. Save your settings. A single language pin uses code `es`.

- Put the cursor in an editable app field, hold Ctrl + Win, speak, then release. Review the transcript before sending it.

Language selection starts no transfer. If automatic routing is off, the model selected on Models remains in use; select a compatible model there. For more detail, see the [setup guide](https://tanzir71.github.io/saydraft/docs/getting-started/).

## Use your voice in everyday Windows apps

Draft in Spanish in an editable chat field, document or text editor. Review accents, names, numbers and punctuation in the result. Spanish uses a shared language choice; the app does not expose a separate decoder setting for every country or guarantee equal accuracy across regional accents.

Speech recognition and text cleanup run locally. There is no account or cloud transcription fallback. With compatible models installed, you can dictate without an internet connection. Optional AI cleanup has its own model requirements; rules-only cleanup needs no text model.

## Is Spanish dictation the same as translating into Spanish?

No. Spanish dictation transcribes Spanish speech. The separate experimental Pro/Labs Translate mode can translate recognized speech into Spanish using an explicitly installed local editing model and a saved output target. You do not need Translate mode to dictate in Spanish.

## What does language support mean here?

This page describes speech-model coverage and app configuration. It does not claim a measured accuracy score for Spanish. Accent, microphone, background noise and mixed speech affect results. The language choice does not translate the app interface or add Translate-mode output targets.
