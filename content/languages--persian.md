# Persian (Farsi) voice typing for Windows.

فارسی

Dictate Persian, also known as Farsi, on Windows without a cloud transcription service. Saydraft recognizes speech locally through the All languages model.

Choose Persian (Farsi), language code fa, in Languages. Persian is distinct from Arabic and Urdu in the menu. Those languages share model files, but selecting one is not a substitute for selecting the language you speak.

Requires the shared All languages speech model (Whisper large-v3-turbo, approximately 1,621.7 MB). Download once in setup or Models, then reuse it offline.

## How to set up Persian (Farsi) dictation

- Follow the [current download and source setup instructions](https://tanzir71.github.io/saydraft/download/). Saydraft is a development preview for Windows 10 and 11.

- In Hub → Settings → Models, review the required model’s size and license. Choose Download / Resume if it is missing; Pause is available.

- Open Languages, enable automatic model choice, and select Persian (Farsi). Save your settings. A single language pin uses code `fa`.

- Put the cursor in an editable app field, hold Ctrl + Win, speak, then release. Review the transcript before sending it.

Language selection starts no transfer. If automatic routing is off, the model selected on Models remains in use; select a compatible model there. For more detail, see the [setup guide](https://tanzir71.github.io/saydraft/docs/getting-started/).

## Use your voice in everyday Windows apps

Draft Persian text in an editable Windows field with right-to-left text support. Review spelling, names, punctuation and joining behavior in the destination app. There is no separate Romanized-Persian transliteration preference in the current app.

Speech recognition and text cleanup run locally. There is no account or cloud transcription fallback. With compatible models installed, you can dictate without an internet connection. Optional AI cleanup has its own model requirements; rules-only cleanup needs no text model.

## Does Persian share the Arabic model?

Persian and Arabic both use the shared All languages model, with separate fa and ar language choices. One installation serves both. Choose Persian alone for a direct hint, or pin more than one language when you switch between them.

## What does language support mean here?

This page describes speech-model coverage and app configuration. It does not claim a measured accuracy score for Persian (Farsi). Accent, microphone, background noise and mixed speech affect results. The language choice does not translate the app interface or add Translate-mode output targets.
