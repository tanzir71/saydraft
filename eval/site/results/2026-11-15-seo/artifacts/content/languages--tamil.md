# Tamil voice typing for Windows.

தமிழ்

Write Tamil messages, notes and drafts with your voice on Windows. Saydraft runs recognition locally using the installed All languages model.

Choose Tamil, language code ta, in Languages. Tamil is a separate choice from Telugu and Hindi, even though their speech model files are shared. A single Tamil pin supplies the decoder with that language hint.

Requires the shared All languages speech model (Whisper large-v3-turbo, approximately 1,621.7 MB). Download once in setup or Models, then reuse it offline.

## How to set up Tamil dictation

- Follow the [current download and source setup instructions](https://tanzir71.github.io/saydraft/download/). Saydraft is a development preview for Windows 10 and 11.

- In Hub → Settings → Models, review the required model’s size and license. Choose Download / Resume if it is missing; Pause is available.

- Open Languages, enable automatic model choice, and select Tamil. Save your settings. A single language pin uses code `ta`.

- Put the cursor in an editable app field, hold Ctrl + Win, speak, then release. Review the transcript before sending it.

Language selection starts no transfer. If automatic routing is off, the model selected on Models remains in use; select a compatible model there. For more detail, see the [setup guide](https://tanzir71.github.io/saydraft/docs/getting-started/).

## Use your voice in everyday Windows apps

Dictate into an editable app field, then review Tamil spelling, vowel signs and proper names. Use a destination font that supports Tamil. The language menu selects recognition, rather than a separate Romanized-Tamil or regional script-conversion setting.

Speech recognition and text cleanup run locally. There is no account or cloud transcription fallback. With compatible models installed, you can dictate without an internet connection. Optional AI cleanup has its own model requirements; rules-only cleanup needs no text model.

## Can I use Tamil without downloading a separate model?

Yes, if All languages is already installed. The same model also serves the other supported multilingual choices. Selecting Tamil reuses those files and starts no transfer. If it is missing, use the explicit Download / Resume action in Models.

## What does language support mean here?

This page describes speech-model coverage and app configuration. It does not claim a measured accuracy score for Tamil. Accent, microphone, background noise and mixed speech affect results. The language choice does not translate the app interface or add Translate-mode output targets.
