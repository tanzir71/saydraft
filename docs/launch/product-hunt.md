## Name

Saydraft

## Tagline

Local voice dictation for Windows

## Description

Hold a shortcut, speak and release to recognize speech, clean the transcript
and attempt delivery into your text field. Saydraft runs Parakeet or Whisper
locally, with rules cleanup and optional local Qwen cleanup. A searchable Hub
keeps History, vocabulary, Snippets, Style and Notes. Free app under MIT.
Current availability: source preview for Windows 10/11 x64; Python 3.13 setup
and explicit model downloads are required. No published installer release yet.

## Product and source link

https://github.com/tanzir71/saydraft

## Maker comment

I'm building Saydraft, an open-source Windows dictation app that keeps speech
recognition and cleanup on the user's PC.

The everyday flow is hold Ctrl+Win, speak, then release. Results go to History
before Saydraft attempts delivery into the original field. You can use rules
cleanup alone or explicitly install an optional local cleanup model. Model setup
shows the download size and license and supports pause/resume.

The Hub brings together History, Dictionary, Snippets, per-app Style, Scratchpad
and Notes. Experimental Pro features include Command editing and spoken
translation. Pro refers to a hardware tier here, not a paid subscription.

This is a source preview. The README has the installation steps and current
limitations; signed releases, broader Windows acceptance and quality
qualification are still in progress. I'd welcome feedback on setup, editing
workflows and cases where delivery needs recovery.
