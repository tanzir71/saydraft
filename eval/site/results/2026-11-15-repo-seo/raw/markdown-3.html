Suggested submission title: Add Saydraft, a local Windows dictation source preview

Suggested submission body:

Saydraft is an MIT Windows 10/11 x64 dictation app using local Parakeet or Whisper recognition and optional local Qwen cleanup. It supports held shortcuts, guarded delivery and local History. It currently runs from source with Python 3.13; an older unsigned verification pre-release predates current source. I am its developer and am proposing it for the dictation-app table. The project README documents setup and remaining quality/Windows acceptance work: https://github.com/tanzir71/saydraft
