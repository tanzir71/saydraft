Saydraft is a free, MIT-licensed Windows project for voice typing with local
models. It is worth evaluating when offline use and inspectable application
source matter to your workflow. A stable public release is still pending;
current users run it from source.

Typeless currently offers desktop apps for macOS, Windows and Linux. Its
[data controls](https://www.typeless.com/data-controls) describe processing on
cloud servers. This comparison concerns where dictation runs, rather than a
claim that one app recognizes speech more accurately.

## Compare the essentials

| Choice | Saydraft | Typeless |
| --- | --- | --- |
| Recognition | [Local speech models](https://github.com/tanzir71/saydraft/blob/main/docs/MODELS.md) | [Cloud processing](https://www.typeless.com/data-controls) |
| Desktop platform | [Windows](https://github.com/tanzir71/saydraft) | [macOS, Windows and Linux](https://www.typeless.com/) |
| Software source | [MIT-licensed application](https://github.com/tanzir71/saydraft/blob/main/LICENSE) | [Commercial application terms](https://www.typeless.com/terms) |
| Pricing | [No subscription](https://github.com/tanzir71/saydraft) | [Free allowance; paid Pro and Enterprise](https://www.typeless.com/pricing) |

Typeless lists Pro at US$30 per member monthly, or US$12 per member per month when
billed yearly. Its free plan includes a weekly word allowance. Verify current
limits and billing terms with the vendor before choosing a plan.

## Dictation, cleanup and local editing

Saydraft combines recognized speech with deterministic formatting and optional
local AI cleanup. Raw and Code modes are available when you want less prose
editing. Names, numbers and meaningful wording still need review.

Experimental Translate and Ask use an explicitly installed local editing model.
Ask opens an answer in a separate note; it does not browse the web. Translate
currently has a narrower tested target set than ordinary multilingual dictation.
These features are not a promise of identical Typeless behavior or equivalent
quality in every language.

Start with <SiteLink path="docs/getting-started/">setup</SiteLink>, then check
<SiteLink path="languages/">language and model coverage</SiteLink>. Existing
models are reused offline, and choosing a language starts no download.
