# Indonesian voice typing for Windows.

Bahasa Indonesia

Write in Bahasa Indonesia with your voice, without a cloud transcription service. Saydraft runs Indonesian speech recognition locally on Windows through its shared All languages model.

Choose Indonesian, language code id. Indonesian and Malay are separate choices: id selects Indonesian, while ms selects Malay. Both reuse the same installed model, so switching between them requires no separate language-pack download.

Requires the shared All languages speech model (Whisper large-v3-turbo, approximately 1,621.7 MB). Download once in setup or Models, then reuse it offline.

## How to set up Indonesian dictation

- Follow the [current download and source setup instructions](https://tanzir71.github.io/saydraft/download/). Saydraft is a development preview for Windows 10 and 11.

- In Hub → Settings → Models, review the required model’s size and license. Choose Download / Resume if it is missing; Pause is available.

- Open Languages, enable automatic model choice, and select Indonesian. Save your settings. A single language pin uses code `id`.

- Put the cursor in an editable app field, hold Ctrl + Win, speak, then release. Review the transcript before sending it.

Language selection starts no transfer. If automatic routing is off, the model selected on Models remains in use; select a compatible model there. For more detail, see the [setup guide](https://tanzir71.github.io/saydraft/docs/getting-started/).

## Use your voice in everyday Windows apps

Use Indonesian dictation for messages, work notes or an email draft in an editable Windows app. Review names, colloquial expressions and repeated words in context. Pin Indonesian alone to provide a direct language hint, or pin it with another language when you switch between them.

Speech recognition and text cleanup run locally. There is no account or cloud transcription fallback. With compatible models installed, you can dictate without an internet connection. Optional AI cleanup has its own model requirements; rules-only cleanup needs no text model.

## Can I use Indonesian and Malay on the same installation?

Yes. Both languages use All languages. Pin up to three languages; with more than one pinned, the model detects the language rather than receiving a single-language hint. Closely related languages and short clips can be confused, so a single pin is useful when you know which language you will speak.

## What does language support mean here?

This page describes speech-model coverage and app configuration. It does not claim a measured accuracy score for Indonesian. Accent, microphone, background noise and mixed speech affect results. The language choice does not translate the app interface or add Translate-mode output targets.
