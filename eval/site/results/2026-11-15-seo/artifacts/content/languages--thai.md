# Thai voice typing for Windows.

ภาษาไทย

Write Thai messages, notes and drafts with your voice. Saydraft turns speech into text locally on your Windows PC once the shared All languages model is installed.

Thai uses language code th. Pin Thai to route directly to the multilingual model instead of starting with the default European-language model. You can also pin Thai alongside English or another language when you switch between them.

Requires the shared All languages speech model (Whisper large-v3-turbo, approximately 1,621.7 MB). Download once in setup or Models, then reuse it offline.

## How to set up Thai dictation

- Follow the [current download and source setup instructions](https://tanzir71.github.io/saydraft/download/). Saydraft is a development preview for Windows 10 and 11.

- In Hub → Settings → Models, review the required model’s size and license. Choose Download / Resume if it is missing; Pause is available.

- Open Languages, enable automatic model choice, and select Thai. Save your settings. A single language pin uses code `th`.

- Put the cursor in an editable app field, hold Ctrl + Win, speak, then release. Review the transcript before sending it.

Language selection starts no transfer. If automatic routing is off, the model selected on Models remains in use; select a compatible model there. For more detail, see the [setup guide](https://tanzir71.github.io/saydraft/docs/getting-started/).

## Use your voice in everyday Windows apps

Use Thai dictation for a message, an email draft or a note in an editable Windows app. Thai word boundaries and spacing differ from English, so review the resulting text in context. Raw mode keeps the recognized words without prose cleanup.

Speech recognition and text cleanup run locally. There is no account or cloud transcription fallback. With compatible models installed, you can dictate without an internet connection. Optional AI cleanup has its own model requirements; rules-only cleanup needs no text model.

## Do I need a Thai keyboard to dictate?

Saydraft delivers recognized Unicode text into an editable field at the cursor. A Thai keyboard layout is useful for manual corrections, but it does not select the speech model. Choose Thai in the app’s language settings.

## What does language support mean here?

This page describes speech-model coverage and app configuration. It does not claim a measured accuracy score for Thai. Accent, microphone, background noise and mixed speech affect results. The language choice does not translate the app interface or add Translate-mode output targets.
