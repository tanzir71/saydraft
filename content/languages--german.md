# German voice typing for Windows.

Deutsch

Dictate German text on your Windows PC with local speech recognition. German is included in Saydraft’s default Parakeet v3 model and is also available in All languages.

Choose German, language code de, in Languages. A German-only pin uses the default model when automatic model choice is enabled. A combination with a language outside that model’s set uses the shared multilingual model instead.

German is included in Parakeet v3, the default speech model. All languages is also compatible. No separate language pack is required.

## How to set up German dictation

- Follow the [current download and source setup instructions](https://tanzir71.github.io/saydraft/download/). Saydraft is a development preview for Windows 10 and 11.

- In Hub → Settings → Models, review the required model’s size and license. Choose Download / Resume if it is missing; Pause is available.

- Open Languages, enable automatic model choice, and select German. Save your settings. A single language pin uses code `de`.

- Put the cursor in an editable app field, hold Ctrl + Win, speak, then release. Review the transcript before sending it.

Language selection starts no transfer. If automatic routing is off, the model selected on Models remains in use; select a compatible model there. For more detail, see the [setup guide](https://tanzir71.github.io/saydraft/docs/getting-started/).

## Use your voice in everyday Windows apps

Draft German messages, notes and documents in an editable Windows app. Review compound words, noun capitalization, umlauts, names and numbers before sending. The app does not expose a separate decoder setting for every German dialect.

Speech recognition and text cleanup run locally. There is no account or cloud transcription fallback. With compatible models installed, you can dictate without an internet connection. Optional AI cleanup has its own model requirements; rules-only cleanup needs no text model.

## Can German recognition work without the multilingual download?

Yes. An installed Parakeet v3 model covers German. The optional All languages model is needed for other language combinations, not for German alone. Both models run locally after explicit setup; neither selection starts a download by itself.

## What does language support mean here?

This page describes speech-model coverage and app configuration. It does not claim a measured accuracy score for German. Accent, microphone, background noise and mixed speech affect results. The language choice does not translate the app interface or add Translate-mode output targets.
