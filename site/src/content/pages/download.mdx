## Set up once. Then go offline.

Review the recommended model, size and license, then start its download in setup.
Progress and pause/resume are available. Later launches reuse your installed files.
The <SiteLink path="docs/getting-started/">setup walkthrough</SiteLink> covers
microphone selection, models, shortcuts and a first practice draft.

Arabic, Bengali, Chinese, Hindi, Indonesian, Japanese, Korean, Malay, Thai and Urdu
use the optional shared All languages model. Download it once; there are no
separate language packs. Portuguese, including Brazilian Portuguese, is also
covered by the default model. Review <SiteLink path="docs/languages/">language
and model choices</SiteLink> before choosing a package.

## Speech model downloads

These transfer sizes come from the pinned app catalog at build time. MB means
1,000,000 bytes. Verified cache entries can reduce what you download; disk use
also includes installed files, temporary transfers and optional retained audio.

The default package includes its language detector. Optional AI cleanup, live
preview and editing features have separate model/runtime requirements. See
<SiteLink path="docs/models/">local models</SiteLink> for those choices and
their limits. Selecting a language never starts a transfer.
