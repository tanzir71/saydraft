## Awesome Voice Typing

The primary [Awesome Voice Typing repository](https://github.com/primaprashant/awesome-voice-typing)
includes open-source dictation applications and a comparison table with platform,
execution and engine columns. Its dictation scope fits Saydraft; acceptance of
an early source preview remains the maintainer's decision.

Suggested table row:

```markdown
| [Saydraft](https://github.com/tanzir71/saydraft) | Windows | Local | Parakeet, Faster Whisper | Hold-to-talk dictation with optional local Qwen cleanup, searchable History, vocabulary, Snippets and per-app Style. Source preview. |
```

Suggested submission title: Add Saydraft, a local Windows dictation source preview

Suggested submission body:

Saydraft is an MIT Windows 10/11 x64 dictation app using local Parakeet or Whisper
recognition and optional local Qwen cleanup. It supports held shortcuts, guarded
delivery and local History. It currently runs from source with Python 3.13;
no published installer release is available. I am its developer and am proposing
it for the dictation-app table. The project README documents setup and remaining
quality/Windows acceptance work: https://github.com/tanzir71/saydraft
