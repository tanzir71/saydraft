Saydraft turns speech into a local draft on Windows. Start with a compatible
installed model, then choose the shortcuts and cleanup that fit your work.
The app is in development; review its results before using them elsewhere.

## Set up and start speaking

- <SiteLink path="docs/getting-started/">Getting started</SiteLink> — microphone,
  model review, explicit downloads and an owned practice field.
- <SiteLink path="docs/shortcuts/">Shortcuts</SiteLink> — hold to speak,
  hands-free, cancellation and paste-last.
- <SiteLink path="docs/models/">Local models</SiteLink> — speech versus cleanup,
  sizes, licenses and offline reuse.
- <SiteLink path="docs/languages/">Languages</SiteLink> — compatible shared
  models, language pins and the difference between coverage and accuracy.

- <SiteLink path="docs/styles/">Styles and cleanup</SiteLink> — tones per app
