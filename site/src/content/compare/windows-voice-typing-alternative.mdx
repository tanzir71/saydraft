Win+H opens Windows voice typing. Microsoft documents an internet requirement
for that feature and says it uses online speech recognition. Saydraft provides
a separate route: install local speech models, then dictate on your PC while
offline.

## Keep Windows features distinct

Windows voice typing and Windows Voice Access are different products. Microsoft
documents [Voice Access](https://support.microsoft.com/en-us/accessibility/windows/voice-access/set-up-voice-access)
as an accessibility feature that can use offline recognition after setup.
Windows editions, languages, hardware and newer Copilot+ features can affect
the options available on a particular PC.

Saydraft is primarily a writing tool. It does not promise full system navigation,
mouse control or an equivalent accessibility command set.

## Try a local writing workflow

Follow <SiteLink path="docs/getting-started/">the setup guide</SiteLink>, choose
an editable field and start with short passages. Review names, numbers and
punctuation. Saydraft keeps local History, offers configurable shortcuts and
can apply optional on-device cleanup; release qualification remains in progress.

Read the <SiteLink path="privacy/">privacy explanation</SiteLink> before using
any dictation tool with sensitive text. Local processing does not replace your
PC's access controls or careful transcript review.
