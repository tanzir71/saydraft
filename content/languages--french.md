# French voice typing for Windows.

Français

Write French messages, notes and emails with your voice on Windows. Saydraft includes French in the default Parakeet v3 speech model, with recognition running on your PC.

Choose French, language code fr, in Languages. French alone routes to Parakeet v3 with automatic model choice enabled. All languages also supports French and is used when your pins include a language outside Parakeet’s set.

French is included in Parakeet v3, the default speech model. All languages is also compatible. No separate language pack is required.

## How to set up French dictation

- Follow the [current download and source setup instructions](https://tanzir71.github.io/saydraft/download/). Saydraft is a development preview for Windows 10 and 11.

- In Hub → Settings → Models, review the required model’s size and license. Choose Download / Resume if it is missing; Pause is available.

- Open Languages, enable automatic model choice, and select French. Save your settings. A single language pin uses code `fr`.

- Put the cursor in an editable app field, hold Ctrl + Win, speak, then release. Review the transcript before sending it.

Language selection starts no transfer. If automatic routing is off, the model selected on Models remains in use; select a compatible model there. For more detail, see the [setup guide](https://tanzir71.github.io/saydraft/docs/getting-started/).

## Use your voice in everyday Windows apps

Dictate a French draft in an editable app field, then review accents, apostrophes, names and punctuation. There is one shared French language choice rather than a separate decoder for every country or regional accent.

Speech recognition and text cleanup run locally. There is no account or cloud transcription fallback. With compatible models installed, you can dictate without an internet connection. Optional AI cleanup has its own model requirements; rules-only cleanup needs no text model.

## Do I need All languages for French alone?

No. French is already included in the default Parakeet v3 model. You can use All languages if it is installed, especially for workflows combining French with languages such as Vietnamese or Tamil. Selecting French does not start a download.

## What does language support mean here?

This page describes speech-model coverage and app configuration. It does not claim a measured accuracy score for French. Accent, microphone, background noise and mixed speech affect results. The language choice does not translate the app interface or add Translate-mode output targets.
