# Bengali voice typing for Windows.

বাংলা

Write in Bengali, also called Bangla, with your voice on Windows. Saydraft recognizes Bengali speech locally using the shared All languages model, without a cloud transcription account.

Choose Bengali, language code bn, in Languages. Pin Bengali alone for a direct recognition hint, or combine it with English or another language when you switch between them. Bengali is already supported by the shared multilingual model; there is no separate Bangla language pack.

Requires the shared All languages speech model (Whisper large-v3-turbo, approximately 1,621.7 MB). Download once in setup or Models, then reuse it offline.

## How to set up Bengali dictation

- Follow the [current download and source setup instructions](https://tanzir71.github.io/saydraft/download/). Saydraft is a development preview for Windows 10 and 11.

- In Hub → Settings → Models, review the required model’s size and license. Choose Download / Resume if it is missing; Pause is available.

- Open Languages, enable automatic model choice, and select Bengali. Save your settings. A single language pin uses code `bn`.

- Put the cursor in an editable app field, hold Ctrl + Win, speak, then release. Review the transcript before sending it.

Language selection starts no transfer. If automatic routing is off, the model selected on Models remains in use; select a compatible model there. For more detail, see the [setup guide](https://tanzir71.github.io/saydraft/docs/getting-started/).

## Use your voice in everyday Windows apps

Draft Bengali messages, emails and notes in an editable Windows app. Review spelling, conjuncts, names, numbers and English loanwords before sending. Raw mode retains the recognized wording without prose cleanup. The language choice does not add a Romanized-Bangla conversion setting.

Speech recognition and text cleanup run locally. There is no account or cloud transcription fallback. With compatible models installed, you can dictate without an internet connection. Optional AI cleanup has its own model requirements; rules-only cleanup needs no text model.

## Do I need a separate Bengali model or keyboard?

Install the shared All languages model once through Download / Resume. It covers Bengali alongside Arabic and other supported languages. A Bengali keyboard can help with manual corrections, but dictation delivers Unicode text and does not depend on choosing that keyboard layout. Selecting Bengali starts no download.

## What does language support mean here?

This page describes speech-model coverage and app configuration. It does not claim a measured accuracy score for Bengali. Accent, microphone, background noise and mixed speech affect results. The language choice does not translate the app interface or add Translate-mode output targets.
