Saydraft: free offline dictation for Windows

Saydraft is a free, open-source offline dictation app for Windows. Local Parakeet/Whisper speech-to-text and on-device cleanup keep processing on your PC.

Speak messy. Paste polished.

Hold a shortcut, speak, then release to transcribe, clean up and attempt delivery into the original editable field. History saves the result before delivery. Installed speech and cleanup models run locally, with no cloud fallback or subscription.

Highlighted speech languages, in alphabetical order: Arabic, Bengali, Brazilian Portuguese, Chinese (Mandarin), Filipino / Tagalog, French, German, Hindi, Indonesian, Japanese, Korean, Malay, Persian (Farsi), Spanish, Tamil, Telugu, Thai, Urdu and Vietnamese, with compatible local models. English is also supported. See the language guide for coverage, shared-model setup and measured accuracy limits.

Coming from Wispr Flow or Typeless?

Start with Ctrl + Win to hold-to-speak, Ctrl + Win + Space for hands-free capture, and Shift + Alt + Z to paste your last words. Review and rebind shortcuts in Settings if another app uses them. Install compatible models once, choose tone/cleanup per app group, then review a short sample in your own workflow.

Frequently asked questions

Does setup need internet? Yes: review model sizes/licenses and start a Download/Resume action. Later launches reuse installed compatible models offline. Selecting a language starts no transfer.

Are Bengali, Arabic and the other languages separate downloads? No. Languages outside the default model's coverage share the optional All languages model; there are no Bengali-only or Arabic-only packs. See language setup.

Is accuracy the same in every language? No. Coverage is distinct from measured quality. The public multilingual evaluation reports its methods and substantial Bengali, Tamil and Telugu errors. Review names, numbers and your own speech before relying on results; owner accuracy acceptance is deferred.

Is it completely offline? Installed recognition and cleanup run locally. Model downloads are explicit; optional GitHub update notices are off by default. The privacy boundary explains Python guard and native-helper firewall limits, as well as Windows clipboard history/sync.

Does it work in every text field? Delivery is guarded. Protected/elevated fields, unsupported selections or focus changes can refuse insertion. Review the saved History result and delivery recovery.

Are Command, Translate, Ask and meeting notes ready for production? They are experimental Pro hardware-profile features with explicit setup/opt-in and separate qualification limits. Pro is a hardware tier, not a paid subscription. See their implementation guides.

What can I install today? Current source uses Windows 10/11 x64 and 64-bit Python 3.13. The public unsigned verification pre-release is older than current source. Use the setup instructions and review release/signing status before choosing an artifact.

Does the web demo record me? No. The current site's prepared-example demo uses canned text, no microphone, models, clipboard or text insertion. Hosted publication is a separate step from a source push.

What works today

  • Local dictation: Parakeet or Whisper recognition, hold-to-talk and hands-free capture, a floating Bar, cancellation, and History before delivery.
  • Cleanup and style: rules for fillers, repetitions, self-corrections, punctuation, and lists; per-app styles; optional local AI cleanup with validation and rules fallback. Normal AI cleanup also checks content-word identity and order after rules; validation details describe the allowed edits and the broader Polished setting. The Hub's Style preview includes staged Dictionary edits and lets you preview a resolved language without changing speech settings.
  • One Hub: Home statistics and recent dictations; searchable History with raw/cleaned changes, Markdown/CSV export, and retry when audio was retained.
  • Scratchpad and Notes: a floating plain-text draft with local autosave, searchable notes, and revision conflict recovery. A shortcut also opens the last dictation's changes. See the Notes guide.
  • Personal vocabulary: searchable Dictionary terms, protected terms, and replacement pairs, with conservative spelling correction in resolved-English dictation; Snippets with date/clipboard variables and import/export. See dictionary behavior and limits.
  • Translate while speaking · Labs: optional Pro translation to English, Spanish or Arabic with per-group targets, local generation and Copy recovery. See the setup and limits.
  • Guided first launch: microphone selection and a level-only test, focused shortcut learning, chat/email dictation practice with before/after review, and a Style quick pick before opening Home.
  • Explicit model setup: provisional PC recommendations, disclosed sizes/licenses, resumable downloads with per-file verification progress, tier overrides, and model storage controls.
  • Whisper mode · experimental: optional gain, AGC, local speech enhancement and more sensitive speech detection for quiet speech. Its whispered-speech accuracy target remains unverified. See setup and scope.
  • Local data controls: no telemetry, audio retention off by default, optional retention limits, a read-only firewall-rule check, and explicit firewall controls for packaged installations.

Run from source

Use Windows 10 or 11, 64-bit Python 3.13, Git, a microphone, and enough free disk space for your selected models. In PowerShell:

git clone https://github.com/tanzir71/saydraft.git
cd saydraft
py -3.13 -m venv .venv
.venv\Scripts\python -m pip install -r requirements.txt
.venv\Scripts\python -m saydraft

Keep the console available while diagnosing startup problems. The current download page also links to GitHub Releases. Review the older verification artifacts' source and signing limits before choosing an installer.

First launch

The setup wizard has six pages: Welcome, Microphone, Set up models, Shortcut, Try it, and Style quick pick.

  1. In Microphone, choose Default Windows input or select Refresh inputs to find a named device. Test input runs a ten-second, level-only check; it does not transcribe or save a recording. Check microphone privacy reads Windows permission status without opening an input; it provides guidance when access is blocked or unknown.
  2. In Set up models, optionally select Check this PC, then Use speech recommendation. This is a provisional capability recommendation, not a measured performance tier. It does not start a download or enable AI cleanup.
  3. Review the speech model, size, and licenses, then select Download / Resume. Setup shows package progress and individual file transfer/checksum phases. Installed-file checks run in the background, including pinned dependencies. After installation, Check model performance measures the selected speech model using bundled audio. It opens no microphone, downloads nothing, and keeps successful measurements separately from saved setup preferences.
  4. In Shortcut, keep the preset, enter a binding, or choose Learn shortcut and press/release your keys. Review any conflicts before continuing.
  5. In Try it, practice in the window's own chat or email field. Preparation opens no microphone. Hold your shortcut or choose Record, then release or choose Stop and preview to review the transcript, cleaned text, and edit chips. Each practice recording is limited to one minute. Audio stays in memory; practice creates no History entries and uses no external paste or clipboard. You can continue without recording.
  6. In Style quick pick, choose Casual or Formal for Messages and Email. The rules preview uses your last practice transcript or a labeled example. Finish rechecks the selected model, saves changed choices, and opens Home after setup work has stopped. Existing intensity and AI settings stay unchanged. Cancel preserves saved preferences; completed downloads and resumable partials remain separate.

In Set up models, Next requires a ready speech model. Catalog packages must pass their file checks; an existing local Whisper model needs a successful offline load check through Check model performance. Finish checks the current model again before saving. Cancel, hiding setup, or going Back revokes a pending Finish. Capability recommendations and measured speed remain distinct. Fresh-profile manual acceptance is still open. See the first-run guide.

Set up once, then go offline

At least one compatible speech model is required to dictate. Model weights are downloaded during explicit setup rather than bundled with the source. Review the recommended speech model, its download size, and its license, then select Download. Progress and pause/resume are available. Later launches reuse installed files. Choosing a language or model never starts a download by itself; you need an installed compatible model before dictating.

Thai, Chinese, Korean, Bengali and Arabic share the optional All languages model. Download it once; there are no separate language packs or language-specific download buttons. Portuguese, including Brazilian Portuguese, is also covered by the default Parakeet v3 model. Choose Portuguese (including Brazilian Portuguese) in Languages; both engines use pt, without a separate Brazil-only decoder setting. Installed models can be selected through language pins and automatic routing; language coverage and routing details explain setup and its limits. Language coverage is not an accent-specific accuracy claim.

Optional AI cleanup is disabled by default. Explicit setup offers pinned Qwen3.5 0.8B or 2B Q4_K_M weights with a local llama.cpp CPU or Vulkan runtime. Recommendations depend on the selected tier and available measurements; they do not enable or download AI cleanup. Rules-only dictation needs no cleanup model. See model details, cleanup setup, and storage controls. Model weights and dependencies retain their own licenses.

Daily use

  1. Click the field where you want text.
  2. Hold Ctrl + Win, speak, then release.
  3. Saydraft transcribes and cleans locally, saves History, and attempts delivery into the original target. Review History if delivery is skipped or fails.

Fresh profiles use these shortcuts. Existing custom bindings are preserved; change them in Hub → Settings → Shortcuts.

Privacy and local files

The dictation path is microphone → local recognition → cleanup → History → delivery. Models are fetched only through explicit setup actions. Python network access is restricted to loopback, requested model downloads and saved opt-in GitHub update checks. Packaged firewall controls add an OS rule for that executable, including its native libraries. Effective Windows policy and separate helper processes have their own verification limits. See the privacy boundary and Verify offline.

Data Default location
Configuration %LOCALAPPDATA%\Saydraft\config.json
History and Notes %LOCALAPPDATA%\Saydraft\history.db
Logs %LOCALAPPDATA%\Saydraft\logs\saydraft.log
Audio, only when retention is enabled %LOCALAPPDATA%\Saydraft\audio
New model installations %LOCALAPPDATA%\Saydraft\models\<id>\<version>

Audio retention is off by default. You can enable Keep forever or Keep N days; expiry preserves History text and statistics. Retry needs retained audio. Compatible legacy model installations remain readable in place. See audio retention and data migration.

Troubleshooting and development

  • No input: check Windows microphone permissions, then open Settings → Microphone, refresh inputs, and run Test input. A missing saved microphone does not silently switch to another device.
  • Next is unavailable in Set up models: finish installing the selected package and its dependencies. For an existing local Whisper model, run Check model performance. If files change later, return to this step and check them again before finishing setup.
  • Practice is unavailable: return to Set up models to install the selected speech model, or to Microphone to check the input. After an app stop or Settings change, choose Prepare practice to start again. If setup cannot confirm that practice stopped, cancel setup and restart Saydraft as prompted.
  • Shortcut conflict: review Settings → Shortcuts and rebind conflicting combinations. Another dictation app may use Ctrl + Win.
  • Text did not insert: open History to review/copy the saved result. Focus changes, protected fields, and elevated targets can prevent delivery; see delivery behavior.
  • Slow setup or recognition: review the model size and installed files in Settings → Models, and use the performance check before selecting a tier.
  • AI cleanup kept the rules result: check that AI cleanup is enabled and its model/runtime are ready. Low-need text, insufficient time, or a rejected model reply can all keep rules output. See the cleanup gate and validator before treating fallback as a failure.
