# Filipino / Tagalog voice typing for Windows.

Filipino / Tagalog

Dictate Tagalog and Filipino text on your Windows PC using local speech recognition. Saydraft exposes the shared multilingual model’s Tagalog language choice.

Select Filipino / Tagalog, code tl, in Languages. The decoder uses its Tagalog code; there is no separate fil decoder or a different language pack for Filipino. This choice does not imply recognition for every language spoken in the Philippines.

Requires the shared All languages speech model (Whisper large-v3-turbo, approximately 1,621.7 MB). Download once in setup or Models, then reuse it offline.

## How to set up Filipino / Tagalog dictation

- Follow the [current download and source setup instructions](https://tanzir71.github.io/saydraft/download/). Saydraft is a development preview for Windows 10 and 11.

- In Hub → Settings → Models, review the required model’s size and license. Choose Download / Resume if it is missing; Pause is available.

- Open Languages, enable automatic model choice, and select Filipino / Tagalog. Save your settings. A single language pin uses code `tl`.

- Put the cursor in an editable app field, hold Ctrl + Win, speak, then release. Review the transcript before sending it.

Language selection starts no transfer. If automatic routing is off, the model selected on Models remains in use; select a compatible model there. For more detail, see the [setup guide](https://tanzir71.github.io/saydraft/docs/getting-started/).

## Use your voice in everyday Windows apps

Draft a message, an email or a note in an editable Windows app. Review English loanwords, names and mixed-language speech. Pin Filipino / Tagalog alone for a direct language hint or add English when you switch between languages.

Speech recognition and text cleanup run locally. There is no account or cloud transcription fallback. With compatible models installed, you can dictate without an internet connection. Optional AI cleanup has its own model requirements; rules-only cleanup needs no text model.

## Does this include every Philippine language?

No. This page describes the model’s tl, or Tagalog, choice and its use for Filipino dictation. Cebuano, Ilocano and other Philippine languages are not separate decoder choices in the current speech catalog. They are not covered by this page’s support claim.

## What does language support mean here?

This page describes speech-model coverage and app configuration. It does not claim a measured accuracy score for Filipino / Tagalog. Accent, microphone, background noise and mixed speech affect results. The language choice does not translate the app interface or add Translate-mode output targets.
