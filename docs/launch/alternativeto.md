## Description

Saydraft is a free, open-source Windows tray app for local voice dictation.
Hold Ctrl+Win, speak, then release. Saydraft recognizes speech on your PC,
cleans the transcript and attempts delivery into the original text field.
History keeps the result before delivery so you can review or copy it when
insertion is skipped.

Recognition uses installed Parakeet or Whisper models. Rules cleanup works
without an AI cleanup model; optional local Qwen cleanup adds a separate model.
Setup shows model sizes and licenses before a user starts a resumable download.
Later launches reuse installed files.

The Hub includes searchable History, Dictionary terms, Snippets, per-app Style,
Scratchpad and Notes. Experimental Pro features include selected-text Command
editing and Translate while speaking. Audio retention and app update checks
default off. Speech recognition and cleanup have no cloud fallback.

This is a source preview for Windows 10/11 x64. Installation currently uses
Python 3.13 and the repository's setup instructions. Signing, installer
publication, broader Windows acceptance and quality qualification remain in
progress. Model weights retain their own licenses.
