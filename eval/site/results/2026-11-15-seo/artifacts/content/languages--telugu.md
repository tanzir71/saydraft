# Telugu voice typing for Windows.

తెలుగు

Use your voice to write Telugu on your own Windows PC. Saydraft provides local Telugu speech recognition through its installed All languages model.

Select Telugu, language code te, in Languages. Telugu and Tamil are separate recognition choices with shared model weights. Pin Telugu alone when you know which language you will speak, or choose up to three pins for a multilingual workflow.

Requires the shared All languages speech model (Whisper large-v3-turbo, approximately 1,621.7 MB). Download once in setup or Models, then reuse it offline.

## How to set up Telugu dictation

- Follow the [current download and source setup instructions](https://tanzir71.github.io/saydraft/download/). Saydraft is a development preview for Windows 10 and 11.

- In Hub → Settings → Models, review the required model’s size and license. Choose Download / Resume if it is missing; Pause is available.

- Open Languages, enable automatic model choice, and select Telugu. Save your settings. A single language pin uses code `te`.

- Put the cursor in an editable app field, hold Ctrl + Win, speak, then release. Review the transcript before sending it.

Language selection starts no transfer. If automatic routing is off, the model selected on Models remains in use; select a compatible model there. For more detail, see the [setup guide](https://tanzir71.github.io/saydraft/docs/getting-started/).

## Use your voice in everyday Windows apps

Draft Telugu notes, messages and documents in an editable Windows app. Review vowel signs, names, numbers and English terms in the output. Recognition quality can vary with accent and audio; the language choice is not an accuracy score.

Speech recognition and text cleanup run locally. There is no account or cloud transcription fallback. With compatible models installed, you can dictate without an internet connection. Optional AI cleanup has its own model requirements; rules-only cleanup needs no text model.

## Can I dictate Telugu and English with the same installation?

Yes. Both are supported by All languages. With Telugu and English pinned together, the model detects the language instead of receiving one fixed hint. Review mixed-language output, especially short phrases and names.

## What does language support mean here?

This page describes speech-model coverage and app configuration. It does not claim a measured accuracy score for Telugu. Accent, microphone, background noise and mixed speech affect results. The language choice does not translate the app interface or add Translate-mode output targets.
