# Urdu voice typing for Windows.

اردو

Write Urdu with your voice on Windows while keeping speech recognition on your own PC. Saydraft uses its installed All languages model for Urdu dictation.

Choose Urdu, language code ur, in Languages. Urdu is separate from Hindi and Arabic in the language menu. All three reuse the same multilingual model; choosing Urdu supplies a recognition hint when it is the only pinned language.

Requires the shared All languages speech model (Whisper large-v3-turbo, approximately 1,621.7 MB). Download once in setup or Models, then reuse it offline.

## How to set up Urdu dictation

- Follow the [current download and source setup instructions](https://tanzir71.github.io/saydraft/download/). Saydraft is a development preview for Windows 10 and 11.

- In Hub → Settings → Models, review the required model’s size and license. Choose Download / Resume if it is missing; Pause is available.

- Open Languages, enable automatic model choice, and select Urdu. Save your settings. A single language pin uses code `ur`.

- Put the cursor in an editable app field, hold Ctrl + Win, speak, then release. Review the transcript before sending it.

Language selection starts no transfer. If automatic routing is off, the model selected on Models remains in use; select a compatible model there. For more detail, see the [setup guide](https://tanzir71.github.io/saydraft/docs/getting-started/).

## Use your voice in everyday Windows apps

Dictate Urdu messages, notes or document drafts into an editable Windows field. Use a destination app with right-to-left text support and review spelling, punctuation and names. Saydraft does not currently offer a Roman Urdu transliteration preference.

Speech recognition and text cleanup run locally. There is no account or cloud transcription fallback. With compatible models installed, you can dictate without an internet connection. Optional AI cleanup has its own model requirements; rules-only cleanup needs no text model.

## Does Urdu require its own download or a separate Arabic model?

No. Urdu and Arabic share All languages along with Hindi, Bengali and other supported speech languages. Install that model once through Download / Resume, then choose Urdu in Languages. The model is reused offline; changing the language choice starts no transfer.

## What does language support mean here?

This page describes speech-model coverage and app configuration. It does not claim a measured accuracy score for Urdu. Accent, microphone, background noise and mixed speech affect results. The language choice does not translate the app interface or add Translate-mode output targets.
