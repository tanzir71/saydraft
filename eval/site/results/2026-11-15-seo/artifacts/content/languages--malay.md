# Malay voice typing for Windows.

Bahasa Melayu

Dictate in Bahasa Melayu on Windows using a speech model that runs on your PC. Install Saydraft’s shared All languages model once, then reuse it for offline Malay voice typing.

Choose Malay, language code ms, in Languages. Indonesian is a separate id choice. The language hint helps select Malay recognition; it does not provide a separate model for every regional variety or a Rumi/Jawi script-conversion control.

Requires the shared All languages speech model (Whisper large-v3-turbo, approximately 1,621.7 MB). Download once in setup or Models, then reuse it offline.

## How to set up Malay dictation

- Follow the [current download and source setup instructions](https://tanzir71.github.io/saydraft/download/). Saydraft is a development preview for Windows 10 and 11.

- In Hub → Settings → Models, review the required model’s size and license. Choose Download / Resume if it is missing; Pause is available.

- Open Languages, enable automatic model choice, and select Malay. Save your settings. A single language pin uses code `ms`.

- Put the cursor in an editable app field, hold Ctrl + Win, speak, then release. Review the transcript before sending it.

Language selection starts no transfer. If automatic routing is off, the model selected on Models remains in use; select a compatible model there. For more detail, see the [setup guide](https://tanzir71.github.io/saydraft/docs/getting-started/).

## Use your voice in everyday Windows apps

Draft Malay messages, meeting notes or documents in an editable app field. Check names, regional expressions and loanwords before sending. Raw mode retains recognized wording. If you dictate English too, you can pin both languages and keep using the same installed multilingual model.

Speech recognition and text cleanup run locally. There is no account or cloud transcription fallback. With compatible models installed, you can dictate without an internet connection. Optional AI cleanup has its own model requirements; rules-only cleanup needs no text model.

## Does Malay need its own download?

No. Malay shares All languages with Indonesian, Thai, Chinese, Korean, Japanese, Bengali and Arabic. Install that model through the explicit Download / Resume action. Selecting Malay or changing a language pin does not start a transfer.

## What does language support mean here?

This page describes speech-model coverage and app configuration. It does not claim a measured accuracy score for Malay. Accent, microphone, background noise and mixed speech affect results. The language choice does not translate the app interface or add Translate-mode output targets.
