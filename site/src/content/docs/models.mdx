## Speech and cleanup are separate stages

The speech model turns audio into words. Deterministic rules can format those
words; an optional text model can make further edits within its time and
preservation checks. Choosing an AI cleanup model does not replace the speech
model, and better prose does not prove better recognition.

## Pick a compatible speech model

Fresh profiles recommend Parakeet v3 int8, with its disclosed tiny Whisper
language detector. It recognizes 25 European languages, including English,
French, German, Spanish and Portuguese. English max uses Parakeet v2.

All languages uses the shared Whisper large-v3-turbo model for the other supported
language choices. Whisper base, small and medium are alternative local options.
Use <SiteLink path="docs/languages/">language pins and model compatibility</SiteLink>
to choose a route for the words you actually dictate.

## Install explicitly, then reuse offline

Setup shows the recommendation, complete package size, source and license before
**Download / Resume**. Pause is available. Downloaded files are verified before
they are ready, and later launches reuse the installed models offline. Choosing
a language, enabling a feature or starting recognition does not fetch missing files.

Settings → Models provides installation/storage status and selected-model
performance checks. Existing local Whisper paths have a compatibility route;
a successful local load is distinct from catalog checksum verification.

## Optional AI cleanup and editing

Rules-only cleanup needs no text model. Optional Qwen cleanup weights and a
compatible llama.cpp CPU or Vulkan runtime add separate transfers. Command,
Translate and Ask share an experimental editing setup with a 4B model; downloading
it does not enable any of those features or change ordinary speech settings.

Runtime choice and model preparation affect latency and memory. A capability
recommendation is provisional; an installed-model check is a measurement of that
test workload, not a promise for every recording. Quality and release-latency
qualification remain separate.

## Quiet speech and live preview

Settings → Microphone has an experimental, default-off **Whisper mode** for quiet
speech: gain, AGC, a more sensitive speech-detection profile and optional local
GTCRN enhancement. Its name does not select the Whisper ASR model. GTCRN setup
is an explicit reviewed download; gain/AGC can be used without enhancement.
The owner whispered-speech accuracy target is still unmeasured.

Live preview is another separate Labs model/setup choice. Its current model is
English-specific. In quiet-speech mode, live partials keep their original signal
while enhanced primary recognition supplies final text.
